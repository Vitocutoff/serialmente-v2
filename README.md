# 🎬 SerialMente

SerialMente è una web app per tracciare le serie TV, monitorare il tempo di visione e organizzare i propri contenuti in modo semplice e personale.

## ✨ Features (in sviluppo)
- Dashboard personalizzata
- Tracciamento episodi e tempo di visione
- Preferiti
- Liste personalizzate
- Profilo utente

## 🧱 Stack
- Next.js 16 (App Router)
- TypeScript
- Tailwind CSS v4
- Clerk (autenticazione)
- Motion (animazioni)

## 🚀 Getting Started

```bash
git clone https://github.com/tuo-username/serialmente-v2
cd serialmente-v2
npm install
npm run dev
